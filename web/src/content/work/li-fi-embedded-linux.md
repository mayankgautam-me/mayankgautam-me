Li-Fi networks on embedded Linux, built as a project scientist in a university research lab. My part was the embedded hardware and software.

- Linux on ARM-based Xilinx MPSoCs, with kernel modules written for the project.
- Work on the networking stack at the kernel layer.
- A custom embedded Linux distribution built with the Yocto Project.
- Boards in Altium Designer, and circuit simulation in Cadence OrCAD.
- DevOps processes for the team, and Python GUIs, Linux shell tools and C# console applications.
