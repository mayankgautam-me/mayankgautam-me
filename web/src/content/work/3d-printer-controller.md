A custom 3D printer controller board built around an AVR microcontroller.

- Silent stepper drivers, so the printer runs quietly.
- Support for IDEX (independent dual extruders), for prints in two materials or colours.
- A Raspberry Pi connection for monitoring and controlling the printer remotely.
