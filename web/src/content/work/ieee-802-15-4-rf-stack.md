A proprietary RF network stack on the IEEE 802.15.4 standard, built as a senior project scientist in a university research lab.

- Custom PHY and MAC layers.
- A GCC build system to compile the stack and debug it on hardware.
- Shell scripts around the stack, and one script that sets it up on different operating systems.
- Packaging and distribution through CI/CD pipelines.

I also managed the project's timeline.
